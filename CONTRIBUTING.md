# Contributing

Thanks for helping improve DataLoam.

This repository is the **public issue tracker and documentation home** for DataLoam. The extension source code is proprietary and is not hosted here, so pull requests with code changes cannot be accepted.

You can contribute by:

- **Reporting bugs**: use the [bug report form](https://github.com/VPALGO-s-r-o/DataLoam/issues/new?template=bug_report.yml). Steps to reproduce, versions, and logs help us fix things faster.
- **Requesting features**: use the [feature request form](https://github.com/VPALGO-s-r-o/DataLoam/issues/new?template=feature_request.yml) and describe the problem you want solved.
- **Improving docs**: use the [documentation form](https://github.com/VPALGO-s-r-o/DataLoam/issues/new?template=documentation.yml) when something on [dataloam.io/docs](https://www.dataloam.io/docs) is wrong or missing.
- **Giving AI feedback**: use the [AI assistant feedback form](https://github.com/VPALGO-s-r-o/DataLoam/issues/new?template=ai_feedback.yml) when the assistant gets something wrong.
- **Upvoting**: add a 👍 reaction to existing issues instead of commenting "+1".

Before opening an issue, please search existing issues and remove any credentials or sensitive data from your report.
