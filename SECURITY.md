# Security Policy

DataLoam connects to your databases, so we take security reports seriously.

## Reporting a vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Report privately by either:

- using [GitHub private vulnerability reporting](https://github.com/VPALGO-s-r-o/DataLoam/security/advisories/new), or
- emailing **support@dataloam.io** with the subject `Security`.

Please include:

- the DataLoam version, editor, and operating system
- a description of the issue and its impact
- steps to reproduce or a proof of concept

Do not include real credentials or production data.

We will acknowledge your report as soon as possible, keep you updated while we investigate, and credit you in the release notes if you wish.

## Supported versions

Security fixes are released for the latest version of DataLoam. Please keep the extension updated.
